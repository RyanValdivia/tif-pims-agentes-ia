# Documento de seguridad — extracto (Clínica San Gabriel S.A.C.)

Aprobado: 2025-11-12. Próxima revisión: 2026-11.

## 3. Respaldos
3.1 Se realizará un respaldo completo **semanal** de SRV-HCE y SRV-ARCH al disco `BKP-01`.
3.2 El disco permanece conectado al servidor para facilitar la operación.
3.3 No se define periodicidad de pruebas de restauración.

## 4. Control de acceso
4.1 Cada usuario tendrá una cuenta personal. *(En la práctica admisión usa cuentas compartidas.)*
4.2 Las contraseñas se renuevan cada 12 meses.
4.3 El acceso remoto se hace por VPN con usuario y contraseña.

## 5. Gestión de incidentes
5.1 Todo incidente se reporta por correo a TI.
5.2 TI decide si lo escala al Oficial de Datos Personales.
5.3 No existe procedimiento ni plazos de notificación a la ANPD; **no se ha definido quién notifica**.
5.4 Las alertas del antivirus se revisan "cuando hay tiempo".

## 6. Registros
6.1 Los registros de la HCE se conservan 90 días.
