## Principios rectores
| Principio | Idea clave | Se usa en |
|---|---|---|
| Legalidad | No recoger datos por medios fraudulentos o ilícitos | RAT |
| Consentimiento | Libre, previo, expreso, informado e inequívoco | RAT, ARCO |
| Finalidad | Uso solo para la finalidad determinada y legítima | RAT, DPIA |
| Proporcionalidad | Datos adecuados, relevantes y no excesivos | RAT, DPIA |
| Calidad | Datos veraces, exactos y actualizados | ARCO |
| Seguridad | Medidas técnicas, organizativas y legales | DPIA |
| Disposición de recurso | El titular puede reclamar | ARCO |
| Nivel de protección adecuado | Especialmente en flujo transfronterizo | RAT, DPIA |

## Datos sensibles
Según la ley, incluyen (entre otros) `[VERIFICAR lista completa en art. 2 num. 5]`:
datos biométricos que identifican a la persona, origen racial y étnico, ingresos económicos, opiniones o convicciones políticas, religiosas, filosóficas o morales, afiliación sindical, salud, vida sexual.
Requieren consentimiento **por escrito** `[VERIFICAR]` y medidas reforzadas.

## Derechos del titular
| Derecho | Qué permite |
|---|---|
| Información | Saber qué datos se tratan, finalidad, destinatarios, plazo |
| Acceso | Obtener sus datos y cómo se recogieron |
| Rectificación / actualización / inclusión | Corregir datos inexactos o incompletos |
| Cancelación / supresión | Eliminar datos cuando ya no sean necesarios o retire el consentimiento |
| Oposición | Oponerse al tratamiento por motivo legítimo |
| Impedir el suministro | Evitar que se entreguen a terceros |
| Tratamiento objetivo | No ser sometido a decisiones basadas solo en tratamiento automatizado |
| Tutela | Reclamar ante la autoridad |
