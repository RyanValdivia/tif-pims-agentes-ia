# Contextos de organización

Aquí se guardan los contextos que se cargan desde la interfaz web (`Contextos` en la barra lateral): inventario, logs y políticas de una organización. El agente los **lee** para verificar un reporte; nunca los modifica. El contenido no se versiona (ver `.gitignore`) porque puede incluir información sensible: use datos de prueba o anonimizados.
